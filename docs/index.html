Quimera

A rule-engine-driven HTTP security header, cookie, token and session analyzer for Burp Suite.

Unlike header-presence checklists, every finding is judged for real exploitability against a modern browser before it is raised. Quimera runs passively by default across Proxy, Repeater, Intruder, Scanner and Target traffic, with optional consent-gated active testing (CORS bypass battery, TRACE, HSTS downgrade, WebDAV, JWT forgery, session-invalidation replay).

Companion browser extension

An optional loopback bridge pairs Quimera with a companion browser extension from the same GitHub organization, letting it read real runtime localStorage, sessionStorage and cookie values instead of guessing from response bodies. The bridge is off by default, requires a pairing token, and is scoped to Burp's Target Scope.
